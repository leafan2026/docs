## 三步快速上手

在本地启动您的文档站点并完成第一次自定义。

### 第一步：配置本地环境

<AccordionGroup>
  <Accordion icon="copy" title="在本地克隆您的文档">
    在入门流程中，如果您还没有 GitHub 仓库，系统已为您创建了一个存放文档内容的仓库。您可以在 [仪表盘](https://dashboard.mintlify.com) 中找到该仓库的链接。
    
    要将仓库克隆到本地以便修改和预览文档，请参考 GitHub 文档中的 [克隆仓库](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) 指南。
  </Accordion>
  <Accordion icon="rectangle-terminal" title="启动预览服务器">
    1. 安装 Mintlify CLI：`npm i -g mint`
    2. 进入您的文档目录并运行：`mint dev`
    3. 打开 `http://localhost:3000` 即可实时查看文档！
    
    <Tip>编辑文件时，预览会自动更新。</Tip>
  </Accordion>
</AccordionGroup>

### 第二步：部署您的更改

<AccordionGroup>
  <Accordion icon="github" title="安装我们的 GitHub App">
    从您的 [仪表盘](https://dashboard.mintlify.com/settings/organization/github-app) 安装 Mintlify GitHub App。
    
    我们的 GitHub App 会自动将您的更改部署到文档站点，无需手动管理部署。
</Accordion>
<Accordion icon="palette" title="更新站点名称和颜色">
    作为第一次修改，我们来更新文档站点的名称和颜色。

    1. 在编辑器中打开 `docs.json`。
    2. 将 `"name"` 字段改为您的项目名称。
    3. 更新 `"colors"` 以匹配您的品牌色。
    4. 保存后，在 `http://localhost:3000` 即可立即看到效果。

    <Tip>尝试修改主色调，立刻就能看到变化！</Tip>
  </Accordion>
</AccordionGroup>

### 第三步：正式上线

<Accordion icon="rocket" title="发布您的文档">
  1. 提交并推送您的更改。
  2. 您的文档将在片刻内更新上线！
</Accordion>
