<Info>
  **前提条件**：
  - Node.js 版本 19 或更高
  - 包含 `docs.json` 文件的文档仓库
</Info>

按照以下步骤在您的操作系统上安装并运行 Mintlify。

<Steps>
<Step title="安装 Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="本地预览">

进入包含 `docs.json` 文件的文档目录，运行以下命令：

```bash
mint dev
```

文档的本地预览将在 `http://localhost:3000` 上可用。

</Step>
</Steps>

## 自定义端口

默认情况下，Mintlify 使用 3000 端口。您可以通过 `--port` 参数自定义运行端口。例如，在 3333 端口运行 Mintlify，使用以下命令：

```bash
mint dev --port 3333
```

如果尝试在已被占用的端口上运行 Mintlify，它会自动使用下一个可用端口：

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Mintlify 版本

请注意，每个 CLI 版本对应特定的 Mintlify 版本。如果本地预览与生产版本不一致，请更新 CLI：

```bash
npm mint update
```

## 验证链接

CLI 可以帮助验证文档中的链接。要找出所有失效链接，使用以下命令：

```bash
mint broken-links
```

## 代码格式化

建议在您的 IDE 中安装扩展以识别和格式化 MDX。如果您使用 VSCode，可以考虑安装 [MDX VSCode 扩展](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) 进行语法高亮，以及 [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) 进行代码格式化。

## 故障排查

<AccordionGroup>
  <Accordion title='错误：无法使用 darwin-arm64 运行时加载 "sharp" 模块'>

    这可能是 Node 版本过旧导致的。请尝试以下步骤：
    1. 删除当前安装的 CLI 版本：`npm remove -g mint`
    2. 升级到 Node v19 或更高版本。
    3. 重新安装 CLI：`npm i -g mint`
  </Accordion>

  <Accordion title="问题：遇到未知错误">
  
    解决方案：进入设备根目录，删除 `~/.mintlify` 文件夹，然后重新运行 `mint dev`。
  </Accordion>
</AccordionGroup>

想了解最新 CLI 版本的变更内容？请查看 [CLI 更新日志](https://www.npmjs.com/package/mintlify?activeTab=versions)。
