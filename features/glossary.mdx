## 常用术语

| 术语 | 含义 |
|------|------|
| **Repository（仓库）** | 存放项目所有文件和历史记录的地方 |
| **Branch（分支）** | 从主线分离出来的独立开发线 |
| **Commit（提交）** | 保存一次代码变更的快照 |
| **Push（推送）** | 将本地提交上传到远程仓库 |
| **Pull（拉取）** | 将远程最新内容同步到本地 |
| **Merge（合并）** | 将两个分支的内容合并在一起 |
| **Pull Request** | 申请将一个分支合并到另一个分支的请求 |
| **Review（审查）** | 团队成员检查代码变更内容 |
| **Approve（批准）** | 审查通过，同意合并 |
| **Conflict（冲突）** | 两个分支对同一处内容有不同修改，需手动解决 |
| **Clone（克隆）** | 将远程仓库完整下载到本地 |
| **Fork（复刻）** | 将别人的仓库复制一份到自己账号下 |
| **diff** | 两个版本之间的差异对比 |
