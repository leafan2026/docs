## 常见分支类型

| 分支名 | 用途 |
|--------|------|
| `main` | 主分支，随时可发布的稳定版本 |
| `develop` | 开发主线，功能开发完成后合并到此 |
| `feature/xxx` | 新功能开发，完成后合并到 develop |
| `fix/xxx` | Bug 修复分支 |
| `hotfix/xxx` | 紧急修复，直接从 main 拉出修复后合并回 main |

## 命名建议

```
feature/sms-notification     # 新增短信通知
fix/login-redirect-error     # 修复登录跳转问题
docs/update-pr-guide         # 更新 PR 文档
```
