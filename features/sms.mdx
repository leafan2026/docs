## 短信类型

金数据支持两种短信：**验证码短信**和**通知类短信**。

| | 验证码短信 | 通知类短信 |
| --- | --- | --- |
| **用途** | 验证填写人手机号真实性 | 发送活动提醒、报名通知等 |
| **签名审核** | 7～10 个工作日 | 7～10 个工作日 |
| **内容审核** | 无需审核（系统默认） | 1 小时内 |

<Tip>
  验证码获取频率：前三次每 60s 一次，第四次起每 180s 一次。
</Tip>

## 计费规则

- 每发送一次验证码，扣 1 条短信量
- 通知类短信无论发送成功或失败，均扣短信量
- 字数计算：签名 + 正文 + 插入字段内容，标点、空格、中英文均算 1 个字
  - ≤70 字：1 条
  - 71～134 字：2 条
  - 每增加 67 字，多计 1 条（上限 500 字）

## 验证码短信

在表单中添加「手机」字段后，在右侧开启「使用短信验证」即可。

![PC|字段|手机字段右侧开启「使用短信验证」功能](/images/sms/syewczdFGT378bsWoChJJRQ8.png)

默认签名为「金数据」，如需自定义，在字段设置中填写企业信息提交，等待 7～10 个工作日审核。

![PC|字段|点击「创建新签名」填写企业名称和统一社会信用代码](/images/sms/anMiCwaR4MnDAtKfg8v7opru.png)

**注意事项：**
- 签名可自定义，但短信内容不可修改
- 签名不能是纯英文或数字，建议明确业务主题

## 发送通知类短信

表单需包含「手机」字段。有三个发送入口：

### 自动化发送

提前配置好触发条件，满足条件时系统自动发送。

**第一步：** 进入表单 → 点击右上角「自动化」→ 选择「发送短信」

![PC|自动化|点击右上角「自动化」选择「发送短信」](/images/sms/XzAE6k7wDatZEvh6QdwGYXKM.png)

**第二步：** 选择触发条件，点击「保存」

![PC|自动化|选择触发条件「新增数据」并点击「保存」](/images/sms/zj4gnK26p55M2EFm3MB41wCx.png)

常用触发条件：

<AccordionGroup>
  <Accordion title="新增数据">
    有人填写提交表单时触发。从 Excel 导入数据不会触发。
  </Accordion>
  <Accordion title="表单支付成功">
    表单数据支付成功时触发，适合支付确认通知。
  </Accordion>
  <Accordion title="修改数据">
    数据发生变动时触发，适合流程流转通知。
  </Accordion>
  <Accordion title="基于数据中的日期">
    按数据中的日期字段设置触发时间，适合生日祝福、日程提醒。
  </Accordion>
  <Accordion title="定时触发">
    按每天/每周/每月周期触发，适合固定提醒。注意：只能发送给指定手机号，不能自动发给表单填写人。
  </Accordion>
</AccordionGroup>

**第三步：** 选择发送对象（指定手机号或插入「手机」字段）

![PC|自动化|发送给「手机」字段点击「插入手机字段」](/images/sms/zJb5D3KaZgsSzd59dCroGiRj.png)

**第四步：** 点击「编辑短信」，选择或新建短信模板

![PC|自动化|点击「点击编辑短信」新建短信模板](/images/sms/E1aucW9PjZmPJx5empVztDUc.png)

![PC|自动化|选择已审核通过的短信模板并点击「确定」](/images/sms/jiKt8LeFGPsfMMd7P1rMD33n.png)

点此查看「[短信签名&内容审核规则](https://help.jinshuju.net/articles/sms-audit)」。

**第五步：** 配置完成，打开右上角开关启动任务

![PC|自动化|任务配置完成点击右上角开关开启任务](/images/sms/rFQVMSk5UnMZUmkNFz2J8WDq.png)

### 表单设置发送

进入「表单设置 → 提醒推送 → 短信提醒推送」，点击「添加短信提醒」，选择触发范围和短信模板即可。

![PC|表单设置|进入「设置——提醒推送——短信提醒推送」点击「添加短信提醒」](/images/sms/Mm5UwgcKWKhTTxPLz3ivsHoA.png)

### 数据页面群发

进入表单数据页面，勾选目标数据，点击工具栏「发短信」。

![PC|数据|勾选数据后点击工具栏「发短信」按钮](/images/sms/9yifoumm1faun4CmAQ3G9cQi.png)

发送后可在「发短信&邮件 → 查看任务记录」里查看发送状态，发送失败的记录可勾选后点「重新发送」。

![PC|数据|点击「发短信&邮件——查看任务记录」](/images/sms/aAfktMhi8eKBKi2vir3hPd9V.png)

## 常见问题

<AccordionGroup>
  <Accordion title="短信消耗顺序是怎样的？">
    套餐内免费短信 → 短信包 → 账户余额。余量和余额都用完后，验证码功能自动关闭，通知短信无法发送，账号可能欠费。
  </Accordion>

  <Accordion title="收不到短信怎么排查？">
    1. 前往[系统设置](https://im.jinshuju.net/system)确认短信余量或账户余额是否充足
    2. 在「个人中心 → 日志 → [短信/邮件日志](https://jinshuju.net/profile/history/sms)」查看是否发送成功
    3. 如显示发送成功但仍收不到，检查手机端：
       - 是否被安全软件拦截
       - 收件箱是否已满
       - 是否长时间未重启
       - 双卡手机可尝试换卡槽或换手机测试

    ![PC|数据|进入「个人中心——日志——短信/邮件日志」查看发送记录](https://help-assets.jinshuju.net/assets/file/11424/6.png)
  </Accordion>

  <Accordion title="发送状态显示「运营商黑名单」怎么办？">
    原因：该号码曾投诉运营商（10086/10010/10000）或回复过退订指令，被列入防骚扰名单。

    解决：让机主发短信至 `1069230504683333`，内容为：「本机确保不再退订或投诉 106 开头的短信，同时申请开通【金数据】。」运营商 1 个工作日内处理。也可拨打运营商人工客服申请解除。
  </Accordion>

  <Accordion title="iOS 上链接被拆成两条显示怎么办？">
    在链接前后各加一个空格，正文和链接就会合并显示。此问题仅出现在部分 iOS 设备上，Android 不受影响。
  </Accordion>

  <Accordion title="开启了短信验证却收不到验证码？">
    **签名为「金数据」时：** 检查是否被拦截、手机状态是否正常、号码是否正确。排查后仍有问题，联系在线客服。

    **自定义签名时：** 检查签名是否过于中性（如「会务通知」「验证」），建议改为与营业执照挂钩的名称，再按上述步骤排查。
  </Accordion>

  <Accordion title="短信中需要插入座机号怎么做？">
    需先提供承诺函。[点击下载](https://im.jinshuju.com/f/xdqsS0/r/gJyfI3)，填写并盖章后提交给在线客服，运营商审核通过后即可插入座机号。
  </Accordion>
</AccordionGroup>
