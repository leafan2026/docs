导航菜单是每个网站上的链接列表。

每次添加新页面时，您可能都需要更新 `docs.json`。页面不会自动出现在导航中。

## 导航语法

我们的导航语法是递归的，这意味着您可以创建嵌套的导航分组。页面名称中不需要包含 `.mdx` 扩展名。

<CodeGroup>

```json 普通导航
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```

```json 嵌套导航
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Getting Started",
          "pages": [
            "quickstart",
            {
              "group": "Nested Reference Pages",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## 文件夹

只需将您的 MDX 文件放入文件夹，并在 `docs.json` 中更新路径即可。

例如，要在 `https://yoursite.com/your-folder/your-page` 创建一个页面，您需要创建名为 `your-folder` 的文件夹，其中包含名为 `your-page.mdx` 的 MDX 文件。

<Warning>

除非嵌套在其他文件夹内，否则不能使用 `api` 作为文件夹名称。Mintlify 使用 Next.js，而 Next.js 将顶级 `api` 文件夹保留用于内部服务器调用。`api-reference` 这样的文件夹名称是可以接受的。

</Warning>

```json 带文件夹的导航
"navigation": {
  "tabs": [
    {
      "tab": "Docs",
      "groups": [
        {
          "group": "Group Name",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## 隐藏页面

未包含在 `docs.json` 中的 MDX 文件不会出现在侧边栏，但可以通过搜索栏访问，也可以通过直接链接打开。
