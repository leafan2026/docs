每个 Mintlify 站点都通过项目根目录下的 `docs.json` 文件进行配置。更改在本地预览中立即生效。

## 身份标识

设置站点的名称、主题和视觉风格。

```json docs.json
{
  "name": "Acme Docs",
  "theme": "mint",
  "favicon": "/favicon.svg",
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg"
  }
}
```

<ResponseField name="name" type="string" required>
  项目名称，显示在浏览器标签标题和站点元数据中。
</ResponseField>

<ResponseField name="theme" type="string">
  视觉主题。可选值：`mint`、`maple`、`willow`、`sequoia`、`prism`。
</ResponseField>

<ResponseField name="favicon" type="string">
  favicon 路径。推荐使用 SVG 格式，确保在各种尺寸下都清晰显示。
</ResponseField>

<ResponseField name="logo" type="object">
  <Expandable title="Logo">
    <ResponseField name="light" type="string">浅色模式下显示的 logo。</ResponseField>
    <ResponseField name="dark" type="string">深色模式下显示的 logo。</ResponseField>
    <ResponseField name="href" type="string" default="/">logo 链接的 URL。</ResponseField>
  </Expandable>
</ResponseField>

## 颜色

```json docs.json
{
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D"
  }
}
```

<ResponseField name="colors.primary" type="string" required>
  主品牌色，用于浅色模式下的高亮、激活状态和强调色。
</ResponseField>

<ResponseField name="colors.light" type="string">
  深色模式下的主色调。
</ResponseField>

<ResponseField name="colors.dark" type="string">
  用于按钮和重要交互元素。
</ResponseField>

<ResponseField name="colors.background" type="object">
  覆盖默认页面背景色。
  <Expandable title="背景">
    <ResponseField name="light" type="string">浅色模式下的背景十六进制颜色。</ResponseField>
    <ResponseField name="dark" type="string">深色模式下的背景十六进制颜色。</ResponseField>
  </Expandable>
</ResponseField>

## 顶部导航栏

配置顶部导航栏链接和主要行动按钮。

```json docs.json
{
  "navbar": {
    "links": [
      { "label": "Support", "href": "mailto:support@example.com" }
    ],
    "primary": {
      "type": "button",
      "label": "Dashboard",
      "href": "https://dashboard.example.com"
    }
  }
}
```

<ResponseField name="navbar.links" type="array">
  显示在顶部导航栏的文字链接。
  <Expandable title="Link">
    <ResponseField name="label" type="string">链接的显示文字。</ResponseField>
    <ResponseField name="href" type="string">链接指向的 URL。</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="navbar.primary" type="object">
  右上角的主要行动按钮。
  <Expandable title="Primary">
    <ResponseField name="type" type='"button" | "github"'>
      `button` 渲染为 CTA 按钮，`github` 渲染为 Star 数量徽章。
    </ResponseField>
    <ResponseField name="label" type="string">按钮标签，type 为 `button` 时必填。</ResponseField>
    <ResponseField name="href" type="string">按钮或徽章链接的 URL。</ResponseField>
  </Expandable>
</ResponseField>

## 导航

将页面组织到标签页和分组中。完整详情请参阅[导航](/essentials/navigation)指南。

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Guides",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ],
    "global": {
      "anchors": [
        {
          "anchor": "Blog",
          "href": "https://example.com/blog",
          "icon": "newspaper"
        }
      ]
    }
  }
}
```

## 上下文工具栏

上下文工具栏悬浮在每个页面上，让读者一键访问 AI 工具和集成服务。完整选项列表请参阅[上下文工具栏](/agent-ready/contextual)。

```json docs.json
{
  "contextual": {
    "options": ["copy", "view", "claude", "mcp", "cursor", "vscode"]
  }
}
```

## 页脚

```json docs.json
{
  "footer": {
    "socials": {
      "x": "https://x.com/yourhandle",
      "github": "https://github.com/yourorg",
      "linkedin": "https://linkedin.com/company/yourco"
    }
  }
}
```

<ResponseField name="footer.socials" type="object">
  显示在页脚的社交链接。支持的键名：`x`、`github`、`linkedin`、`discord`、`slack`、`facebook`、`instagram`、`website`。
</ResponseField>
