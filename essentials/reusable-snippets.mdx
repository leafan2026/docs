title: "可复用片段"
description: "一次编写，随处复用。使用 snippet 保持多页面内容同步"

---

任何在多个页面重复出现的内容都适合提取为 snippet。在 `snippets/` 目录中创建一次文件，在需要的地方导入，更新会自动同步到所有引用处。

<Note>
  `snippets/` 目录中的文件不会被渲染为独立页面，它们只会在被导入的地方显示。
</Note>

## 内容片段

最简单的用法：在 snippet 文件中编写 MDX 内容，并作为组件导入。

```mdx snippets/prerequisites.mdx
Before you begin, make sure you have:
- Node.js 18 or higher
- An API key from your [dashboard](https://dashboard.example.com)
```

使用根相对路径将其导入任意页面：

```mdx your-page.mdx
---
title: Install the SDK
---

import Prerequisites from '/snippets/prerequisites.mdx';

<Prerequisites />

## Installation
...
```

也可以使用相对路径导入，这样可以在编辑器中通过 CMD+点击跳转到 snippet 文件：

```mdx
import Prerequisites from '../snippets/prerequisites.mdx';
```

## 变量片段

从 snippet 文件中导出具名常量，以复用产品名称、版本号或 URL 等值。

```mdx snippets/vars.mdx
export const sdkVersion = '3.2.0';
export const baseUrl = 'https://api.example.com/v1';
```

导入后可在行内使用：

```mdx your-page.mdx
import { sdkVersion, baseUrl } from '/snippets/vars.mdx';

当前 SDK 版本为 **{sdkVersion}**。

所有请求发送至 `{baseUrl}`。
```

## 组件片段

对于需要根据使用位置动态变化的 snippet，可以导出一个接受 props 的箭头函数组件。

```mdx snippets/endpoint-note.mdx
export const EndpointNote = ({ method, path }) => (
  <Note>
    本指南介绍 <code>{method} {path}</code> 端点。
    完整详情请参阅 <a href="/api-reference/introduction">API 参考</a>。
  </Note>
);
```

* 使用箭头函数语法（`const Foo = () => ...`）。
* snippet 文件中不支持 `function` 关键字。
* MDX 语法无法在箭头函数体内编译，请在其中使用纯 HTML 标签，或改用默认导出。

渲染时传入 props：

```mdx your-page.mdx
import { EndpointNote } from '/snippets/endpoint-note.mdx';

<EndpointNote method="POST" path="/v1/users" />
```

## Snippet 嵌套导入

Snippet 可以导入其他 snippet，适合将较大的共享章节拆分为更小的片段组合。

```mdx snippets/auth-intro.mdx
import AuthNote from '/snippets/auth-note.mdx';

## 认证

所有端点都需要 bearer token。

<AuthNote />
```
