Mintlify 组件让您可以使用 MDX 构建丰富的交互式文档页面。以下是一些常用组件。

完整组件列表请参阅 Mintlify 文档中的[组件概览](https://mintlify.com/docs/components)。

## 提示框

使用提示框来吸引读者注意重要信息。

<Note>**Note** 用于提供帮助读者的通用信息。</Note>

<Tip>**Tip** 用于强调有用的快捷方式或最佳实践。</Tip>

<Warning>**Warning** 用于标记可能引发问题的内容。</Warning>

<Info>**Info** 提示框提供补充说明。</Info>

```mdx
<Note>**Note** 用于提供帮助读者的通用信息。</Note>

<Tip>**Tip** 用于强调有用的快捷方式或最佳实践。</Tip>

<Warning>**Warning** 用于标记可能引发问题的内容。</Warning>

<Info>**Info** 提示框提供补充说明。</Info>
```

## 卡片

卡片用于将读者链接到其他页面或资源。

<Columns cols={2}>
  <Card title="API 参考" icon="terminal" href="/api-reference/introduction">
    从您的 OpenAPI 规范自动生成文档。
  </Card>
  <Card title="快速入门" icon="rocket" href="/quickstart">
    三步启动您的文档。
  </Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="API 参考" icon="terminal" href="/api-reference/introduction">
    从您的 OpenAPI 规范自动生成文档。
  </Card>
  <Card title="快速入门" icon="rocket" href="/quickstart">
    三步启动您的文档。
  </Card>
</Columns>
```

使用 `<Columns cols={N}>` 控制网格宽度。没有 `href` 的卡片将作为信息面板渲染。

## 步骤

步骤组件用于清晰展示编号流程。

<Steps>
  <Step title="安装包">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="初始化">
    在项目根目录运行初始化命令。
    ```bash
    npx my-package init
    ```
  </Step>
  <Step title="准备就绪">
    开始在代码中使用该包。
  </Step>
</Steps>


## 标签页

标签页让读者在不同内容间切换——适合展示不同语言、环境或平台的版本。

<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add my-package
    ```
  </Tab>
</Tabs>

````mdx
<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package

  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash

    ```
  </Tab>
</Tabs>
````

## 折叠面板

折叠面板将内容隐藏在开关后——适用于 FAQ 或可选的详细信息。

<AccordionGroup>
  <Accordion title="这个产品是做什么的？">
    第一个问题的简短回答，保持简洁。
  </Accordion>
  <Accordion title="定价是如何计算的？">
    第二个答案。使用所需的空间来说明。
  </Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="这个产品是做什么的？">
    第一个问题的简短回答。
  </Accordion>
  <Accordion title="定价是如何计算的？">
    第二个答案。
  </Accordion>
</AccordionGroup>
```

## 框架

将图片或其他内容包裹在 `Frame` 中，可添加带样式的边框和圆角。

<Frame>
  <img src="https://mintlify-assets.b-cdn.net/bigbend.jpg" alt="大弯曲风景" />
</Frame>

```mdx
<Frame>
  <img src="/images/screenshot.png" alt="应用截图" />
</Frame>
```

## 代码组

`CodeGroup` 以标签页形式展示多个代码片段——非常适合用多种语言展示同一示例。

<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  const users = await response.json();
  ```

  ```python Python
  import requests
  response = requests.get('https://api.example.com/users')
  users = response.json()
  ```

  ```bash curl
  curl https://api.example.com/users
  ```
</CodeGroup>

````mdx
<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  ```

  ```python Python
  response = requests.get('https://api.example.com/users')
  ```
</CodeGroup>
````
